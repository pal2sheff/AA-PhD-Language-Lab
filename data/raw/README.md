# data/raw — исходные данные

Исходные данные помещает только пользователь. Файлы неизменны: агенты их читают, но не правят (запрет записи закреплён в `.claude/settings.json`).
Содержимое каталога исключено из Git (`.gitignore`), потому что репозиторий публичный.
Идентифицируемые сведения о пациентах не загружаются во внешние сервисы. Подробно: `docs/HQ_RULES.md`.
