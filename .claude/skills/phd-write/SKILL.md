# /phd-write — текст

Задача: $ARGUMENTS

**Маршрут:** scientific-writer → independent-reviewer → исправления → defense-presenter (при необходимости оформления).

**Порядок:**
1. Главная беседа проверяет, что есть утверждённая структура и входные материалы. Если их нет, сначала составляется план раздела и перечень недостающего.
2. `scientific-writer`: текст в `manuscript/` или `publications/`.
3. `independent-reviewer`: отдельные задания по нужным режимам: «Источники», «Стандарты описания», «Научная добросовестность».
4. `scientific-writer` исправляет текст по отчёту.
5. `defense-presenter` оформляет DOCX, таблицы и рисунки, если это нужно.

**Проверка:** все метки `[НУЖЕН ИСТОЧНИК]` и `[НУЖЕН РЕЗУЛЬТАТ]` перечислены в итоговом отчёте. Внешняя отправка выполняется только по отдельному поручению.
