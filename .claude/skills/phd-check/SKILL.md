# /phd-check — независимая проверка

Режим и объект: $ARGUMENTS

Режимы: `источники`, `методология`, `статистика`, `стандарты`, `добросовестность`, `оппонирование`.

**Порядок:**
1. Главная беседа уточняет режим, объект, эталон (источники, код, данные, руководство) и критерии. Если режим не указан, его нужно выбрать или спросить.
2. Для каждого режима запускается отдельное задание `independent-reviewer`.
3. Проверка выполняется только вызовом субагента `independent-reviewer`, потому что ограничения записи действуют только у него. Проверяющий не должен быть автором проверяемого материала в той же задаче.
4. Отчёты сохраняются в `reports/reviews/`. Главная беседа сравнивает отпечатки `.claude/hooks/repo_snapshot.sh`, снятые до и после проверки.
5. Исправления назначаются автору материала. Повторная проверка закрывает замечания по столбцу «Как проверить исправление».

**Результат:** таблица замечаний с важностью и перечень того, что не удалось проверить, с причинами.
