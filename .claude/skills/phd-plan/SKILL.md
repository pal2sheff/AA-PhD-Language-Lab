# /phd-plan — план работ

Период или цель: $ARGUMENTS

**Входные данные:** `project/PhD_Control.md`, `project/DECISION_LOG.md`, `project/OPEN_QUESTIONS.md`, `ethics/REQUIREMENTS.md`, `project/Research_Profile.md`.

**Исполнители и порядок:**
1. `phd-secretary` составляет проект плана: задачи, сроки, зависимости, исполнители штаба.
2. `scientific-director` подключается, только если план затрагивает научные приоритеты (порядок задач исследования, тип обзора, дизайн).
3. Главная беседа сводит ответы и показывает план пользователю.

**Результат:** план в беседе. После одобрения пользователем phd-secretary вносит его в `project/PhD_Control.md`.

**Проверка:** у каждой задачи есть один ответственный, срок и критерий выполнения. Требования и сроки вузов берутся только из `ethics/REQUIREMENTS.md`. Если требования нет, создаётся задача для ethics-compliance.
