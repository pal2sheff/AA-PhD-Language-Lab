# /phd-status — состояние проекта

Раздел: $ARGUMENTS (если пусто, нужна общая сводка).

**Входные данные:** `project/PhD_Control.md`, `project/DECISION_LOG.md`, `project/OPEN_QUESTIONS.md`, `ethics/REQUIREMENTS.md`, последние файлы в `reports/`.

**Исполнители и порядок:**
1. Если вопрос простой и ответ есть в одном файле, главная беседа отвечает сама.
2. Иначе вызывается `phd-secretary` в режиме «Статус» с перечнем входных файлов.

**Результат:** ответ в беседе по форме «выполнено (с подтверждением) / запланировано / под угрозой / требует решения / следующий шаг». Файлы изменяются, только если пользователь попросил обновить `PhD_Control.md`. В этом случае ответственный за запись — phd-secretary.

**Проверка:** статус «выполнено» без подтверждающего файла или решения не ставится. Если `PhD_Control.md` отсутствует, об этом сообщается первой строкой.
