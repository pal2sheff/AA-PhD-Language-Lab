# AA-PhD-Language-Lab

Подготовка к языковым экзаменам *(исходное описание репозитория сохранено)*.

С 20.10.2026 здесь также размещён **Диссертационный штаб**: проектная конфигурация Claude Code для сопровождения докторантуры, от поступления до защиты.

## Как пользоваться

1. Откройте Claude Code в корне репозитория. Главная беседа выступает начальником штаба и сама выбирает исполнителей.
2. Ставьте задачу обычными словами или командой:

| Команда | Что делает |
|---|---|
| `/phd-status [раздел]` | Состояние проекта: выполнено, запланировано, под угрозой |
| `/phd-plan [период]` | План работ с исполнителями и сроками |
| `/phd-search <тема> [поток]` | Поисковая стратегия и поиск литературы |
| `/phd-article <номер/DOI/PDF>` | Разбор одной статьи |
| `/phd-review <тема>` | Обзор литературы |
| `/phd-protocol [раздел]` | Протокол исследования |
| `/phd-stats <задача>` | Данные и статистика |
| `/phd-write <задача>` | Главы, статьи, перевод, ответы рецензентам |
| `/phd-check <режим> <файл>` | Независимая проверка |
| `/phd-defense <этап>` | Подготовка защиты |
| `/phd-tools [задача]` | Инструменты и подключения |

3. Загрузите исходные документы: `Research_Profile.md` и `PhD_Control.md` в `project/`, реестр статей и график чтения в `literature/`.

## Структура

```
.claude/agents/   12 агентов штаба
.claude/skills/   11 команд /phd-*
.claude/hooks/    защита оригиналов при независимой проверке
docs/             регламент, каталог агентов, маршруты, подключения
project/          паспорт, прогресс, журнал решений, открытые вопросы
sources/          полные тексты (с соблюдением авторских прав)
literature/       реестр, журналы поиска, разборы, матрицы доказательств
protocol/         протокол и его блоки (clinical, lab, sap)
ethics/           ЛЭК, согласия, реестр официальных требований
data/raw/         исходные данные (не изменяются, не попадают в Git)
data/processed/   производные данные (не попадают в Git)
data/synthetic/   синтетические данные для отладки
analysis/         код, журналы, окружение; review_runs/ — повторные расчёты
manuscript/       главы диссертации
publications/     статьи, подача, календарь
defense/          презентации, доклад, банк вопросов, пакет документов
reports/          отчёты; reviews/ — заключения проверяющего
```

## Важно
- Репозиторий публичный. Персональные медицинские данные и документы ЛЭК с персональными данными сюда не помещаются.
- Агенты не заменяют научного руководителя, ЛЭК и диссертационный совет.
- Подробные правила: `docs/HQ_RULES.md`.
