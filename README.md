# AA PhD Language Lab

**«90 дней до IELTS и КАЗТЕСТ»** — персональная образовательная платформа для самостоятельной подготовки к IELTS Academic (цель 5.0–5.5) и КАЗТЕСТ. Интерфейс на русском, основной режим — интенсив 90 дней (доступны 6 и 9 месяцев), основное устройство — iPhone.

---

## Быстрый старт

Нужен Node.js 20+.

```bash
npm install
npm run dev          # разработка: http://localhost:5173
```

Сборка и запуск как на «боевом» сервере:

```bash
npm run build
npm run server       # http://localhost:8787 (приложение + API)
```

Проверки:

```bash
npm run typecheck    # TypeScript
npm test             # 51 модульный тест (Vitest)
npm run e2e          # 16 сквозных сценариев в Chromium (нужен запущенный npm run server)
```

### Как пользоваться на iPhone

1. Откройте адрес приложения в Safari.
2. «Поделиться» → «На экран „Домой“» — приложение откроется как отдельное (PWA), работает офлайн.
3. Включите казахскую клавиатуру: Настройки → Основные → Клавиатура → Клавиатуры → «Казахская».
4. Регулярно делайте **Экспорт JSON** (Настройки → Данные): Safari может удалить данные сайтов, которыми долго не пользовались.

## Архитектура

| Слой | Технология | Где |
|---|---|---|
| Интерфейс | React 18 + TypeScript, Tailwind CSS 4, Vite 6 | `src/` |
| Маршрутизация | hash-роутер (работает на любом статическом хостинге и в PWA) | `src/lib/router.ts` |
| Состояние | единое хранилище + Immer, автосохранение через 250 мс и при сворачивании | `src/lib/store.ts` |
| Хранение | IndexedDB (основное) + копия в localStorage, миграция версий, экспорт/импорт JSON | `src/lib/storage.ts`, `src/lib/backup.ts` |
| Интервальное повторение | FSRS-4.5 (опубликованные веса), цель запоминания 0,9 | `src/lib/srs.ts` |
| Диагностика | адаптивный «лестничный» алгоритм по 4 навыкам × 6 заданий | `src/lib/diagnostic.ts` |
| Планирование | этапы, контрольные точки, календарь, ежедневный план, слабые темы | `src/lib/planner.ts` |
| Шкалы | IELTS (сырые баллы → band, округление общего балла, вес Task 2), КАЗТЕСТ (пороги — только официальные, вводятся вручную) | `src/lib/scoring.ts` |
| Речь | Web Speech API (синтез и распознавание), MediaRecorder (запись) | `src/lib/speech.ts` |
| Проверка письма без AI | правила: объём, структура, связки, повторы, типичные ошибки русскоязычных; для казахского — окончания мн. числа и раскладка | `src/lib/writingCheck.ts` |
| AI-преподаватель | клиент → собственный сервер → Claude API (`@anthropic-ai/sdk`) | `src/lib/ai.ts`, `server/` |
| Синхронизация | собственный сервер, одна копия на токен | `server/index.mjs` |
| PWA | manifest + service worker (офлайн-оболочка) | `public/` |

Контент — обычные TypeScript-модули, которые легко расширять:

```

  diagnostic.ts                 банк диагностики (48 + 48 заданий)
  vocab.ts                      тематические словари (≈ 85 EN, ≈ 60 KK слов) + слова уроков

  kaztest.ts                    Тыңдалым (20 вопросов), Оқылым (тексты 1–2), Жазылым, Айтылым
  practice.ts                   произношение и аудиодиктанты
  conversation.ts               13 сценариев разговорного тренажёра
```

## Интерфейс и дизайн-система

- **Палитра** (токены в `src/index.css`, `@theme`): фон `#F5F7FA`, карточки `#FFFFFF`, текст `#172B4D` / `#526273`; английский и IELTS — `#2855A1`, казахский и КАЗТЕСТ — `#0F766E`; тёплый акцент `#B58A45` (только декоративно, для текста — `#8A6428`). Все цвета текста проверены на контраст WCAG AA.
- **Шрифт**: Inter (самостоятельно размещённый пакет `@fontsource-variable/inter`, кириллица и казахские буквы, работает офлайн), запасной — системный.
- **Навигация**: на компьютере — боковая панель с группами (Обучение, Практика, Экзамены, Прогресс, Дополнительно); на iPhone — нижняя панель из пяти пунктов: Главная, Сегодня, Курсы (`#/courses`), Экзамены (`#/exam-center`), Ещё. Во время урока, диагностики, экзамена и повторения нижняя панель скрыта (режим фокуса), главная кнопка действия закреплена внизу экрана с учётом safe area.
- **Логотип**: монограмма «AA» с тёплой перемычкой (`src/components/Logo.tsx`, `public/icons/icon.svg`); PNG-иконки генерируются `node scripts/make-icons.mjs`.

## AI-преподаватель и синхронизация (сервер)

Базовые функции работают **без сервера и без оплаты**. Сервер нужен для платных AI-функций и для синхронизации между компьютером и iPhone.

```bash
export ANTHROPIC_API_KEY=sk-ant-...        # ключ Anthropic API (только на сервере!)
export APP_ACCESS_TOKEN=длинный-секрет      # защищает /api/ai от посторонних
export SYNC_TOKENS=ваш-личный-токен-от-16-символов
# необязательно: ANTHROPIC_MODEL (по умолчанию claude-opus-5-5), PORT, DATA_DIR, ALLOWED_ORIGIN
npm run build && npm run server
```

В приложении: **Настройки → AI-преподаватель** (адрес сервера + APP_ACCESS_TOKEN) и **Настройки → Облачная синхронизация** (адрес + токен синхронизации, одинаковый на всех устройствах).

Безопасность:
- ключ Anthropic API никогда не попадает в браузер;
- доступ к AI — по токену, ограничение частоты (30 запросов/мин);
- синхронизация — только с токенами из `SYNC_TOKENS`, файл данных доступен только владельцу процесса, предыдущая версия сохраняется как `.prev.json`;
- аудиозаписи на сервер не отправляются: для анализа речи передаётся только текстовая транскрипция и только по нажатию кнопки;
- раздача статики защищена от выхода за пределы `dist/`.

Развёртывание: любой хостинг с Node.js (VPS, Render, Railway, Fly.io). Нужен HTTPS — без него iPhone не даст доступ к микрофону. Только статическая версия (без AI и синхронизации) — папку `dist/` можно выложить на GitHub Pages / Netlify.

## Что готово (этап 1 — MVP — и большая часть этапа 2)

**Обучение**
- Мастер первого запуска: программа 90 / 180 / 270 дней, нагрузка 30–120 минут, дата начала.
- Адаптивная диагностика обоих языков по 6 компонентам; можно проходить частями. Письмо и говорение сохраняются как образцы и явно помечаются «не проверено» (без AI).
- Результат диагностики: ориентировочный уровень, сильные/слабые навыки, грамматические пробелы, приоритеты, пересчёт распределения времени, **оценка реалистичности цели** по ориентирам учебных часов CEFR (с явной оговоркой).
- **24 полноценных урока** (12 EN, 12 KK) по методике из 9 шагов: цель → теория (таблицы, схемы, морфологический разбор для казахского) → примеры с переводом и озвучкой → типичные ошибки → разминка → упражнения → аудирование и повтор за диктором → контроль → итог. Кнопки «Объясни проще», «Покажи пример», «Объясни мою ошибку», «Дай ещё упражнение», «Повтори правило», «Добавить в словарь», «Вернуться к теме» работают без AI (подготовленные объяснения), а при подключённом AI дают расширенный ответ.
- 5 типов упражнений: выбор, пропуск, порядок слов, перевод, аудирование (выбор / запись).
- Урок считается освоенным при ≥ 70 % в контроле; при меньшем результате тема уходит в повторение, но программа не блокируется.

**Планирование**
- Полный календарь на весь срок: 4 этапа, 13 учебных недель с целями и измеримыми результатами, контрольные точки (дни 1/14/30/45/60/75/90, масштабируются для 6 и 9 месяцев), дни пробных экзаменов, даты экзаменов и подачи документов.
- В календаре отличается тема с готовым материалом (✓) от запланированной, но ещё не созданной.
- Ежедневный план из блоков 5–20 минут: перестановка, перенос на завтра (без роста нагрузки), выбор темы самостоятельно, повтор пройденного урока, пересборка; автоматическая отметка выполнения; учёт фактического активного времени.
- Пропуски не создают «долгов»: темы сдвигаются, при нехватке срока — предупреждение с рекомендацией.
- Адаптация: темы с точностью < 60 % или ≥ 2 открытыми ошибками автоматически попадают в план; освоенная тема — ≥ 80 % в последних 10 ответах.
- Режим «Экстренная подготовка» за 14 дней до экзамена.

**Тренажёры**
- Словарь с FSRS: 5 режимов (знакомство, выбор перевода, вспоминание с самооценкой, написание по памяти / на слух, слово в предложении), статусы новое / изучается / к повтору / освоено (слово не считается освоенным после одного ответа).
- «Мои ошибки»: 7 категорий, история, повторяемость, статус; «Повторить мои ошибки» собирает занятие из **новых** заданий той же темы.
- Произношение (повтор за диктором, запись, сравнение распознанного текста) и аудиодиктанты 5 форматов.
- IELTS: Reading 40 вопросов / 60 минут, Listening 40 вопросов (4 части, карта), Writing Task 1 (графики, процесс, таблица) и Task 2 с таймером и автопроверкой, Speaking Part 1–3 и полный пробный экзамен 11–14 минут с виртуальным экзаменатором.
- КАЗТЕСТ: Тыңдалым 20 вопросов (полный формат), Оқылым — тексты 1–2 (16 из 40 вопросов, помечено), Жазылым (описание изображения + эссе), Айтылым (мнение + ситуация).
- Пробные экзамены: экзаменационный режим (таймер, без подсказок, аудио один раз) и учебный; band по ориентировочной таблице IELTS; общий балл — только если проверены все 4 компонента.
- Разговорный тренажёр: 13 сценариев (в том числе вымышленные медицинские), голос или текст; без AI — проверка ключевых конструкций и образцы ответов, с AI — свободный диалог и разбор.
- Статистика: минуты по дням (EN/KK), точность по неделям, динамика секций, три категории «проверено / предварительно AI / не проверено».
- Модуль «Английский для врача и исследователя»: термины (диабетическая стопа, митохондрии, иммунное старение, методология), разбор учебной аннотации, фразы для докладов и переписки, тест.

**Данные**: IndexedDB + резерв, экспорт/импорт JSON, облачная синхронизация через свой сервер, удаление всех данных, запрос постоянного хранения.

## Ограничения и честные оговорки

- **Это не полностью наполненный 90-дневный курс.** Программа содержит 74 темы: для 24 есть полноценные уроки, 29 тем (словарные модули и экзаменационные навыки) покрыты тренажёрами, а 21 грамматическая тема запланирована в календаре, но учебный материал для неё ещё не создан — она помечена «в разработке».
- **Озвучка** — синтезатор речи устройства. Это не записи носителей и не «акценты IELTS»: приложение показывает только реально доступные на устройстве голоса (en-GB / en-US / en-AU / en-NZ). Казахского голоса на iPhone обычно нет — тогда текст показывается для чтения, а для аудио можно включить запасной голос (с пометкой о неточности) или добавить записи (см. ниже).
- **Произношение** автоматически не оценивается: распознавание показывает лишь разборчивость слов.
- **КАЗТЕСТ**: структура блоков взята из технического задания; официальные страницы testcenter.kz / adilet.zan.kz из среды разработки были недоступны — **сверьте структуру перед экзаменом**. Пороги и шкала 160 баллов не встроены: введите официальные пороги в Настройках; до этого результаты — учебные проценты.
- **IELTS**: таблицы перевода баллов ориентировочные; тексты Reading немного короче экзаменационных; повторное прохождение того же теста завышает результат.
- **Оценки AI** письма и речи всегда помечены как предварительные; без AI балл за Writing/Speaking не выставляется.
- Распознавание речи в Safari/Chrome выполняют сервисы Apple/Google — об этом есть предупреждение рядом с микрофоном.
- Все тексты, задания и аудиосценарии оригинальные; медицинские сценарии и аннотация вымышлены.

## Что осталось сделать (этапы 2–4)

1. **Контент**: уроки для 21 оставшейся грамматической темы программы (EN: Past Continuous, предлоги, герундий/инфинитив, относительные придаточные, косвенная речь, Present Perfect Continuous, академические конструкции; KK: көмектес септік, нақ осы шақ, будущее время, модальность, шартты рай, есімше, көсемше, сложные предложения).
2. **Банк экзаменов**: КАЗТЕСТ Оқылым тексты 3–4 (24 вопроса) → полный формат; второй и третий полные тесты IELTS Reading/Listening (новые задания для контрольных точек); форматы Matching Features, Table Completion, Diagram Labelling.
3. **Аудио**: подстановка реальных записей (`public/audio/manifest.json`: id → файл) для казахских уроков и Тыңдалым.
4. **AI**: генерация новых упражнений по слабым темам в формате приложения (с проверкой), учёт истории ошибок в разговорном тренажёре.
5. **Синхронизация**: автоматическая (сейчас — кнопками «Отправить» / «Загрузить») и слияние изменений вместо «побеждает последняя версия».
6. **Аналитика**: прогноз по каждому навыку на основе динамики контрольных точек.
7. Разделение бандла (сейчас один JS-файл ≈ 256 КБ gzip).
