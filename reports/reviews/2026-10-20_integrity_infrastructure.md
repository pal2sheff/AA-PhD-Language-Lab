## Часть C. Новые обходы хука

Метод: каждая команда подана **только на вход хука** в виде JSON, без исполнения (`analysis/review_runs/2026-10-20_hook/probe_bypasses.py`). Код 0 означает, что хук пропустил бы команду. Контрольная `rm CLAUDE.md` дала код 2. Действие механизмов записи подтверждено **только на приманках** в `analysis/review_runs/2026-10-20_hook/`: `sort -o` обнулил файл; `python3 -Ic '…#/../analysis/review_runs/x'` записал файл; `cp -l` + `echo >` изменили исходный файл через жёсткую ссылку; `echo XY 1<>` перезаписал начало файла («XY|GINAL»); `uniq /dev/null F` создал пустой файл. Механизмы, которые запускают чужие программы (`rg --pre`, `git grep -O`, `sort --compress-program`, копия bash), **не исполнялись**. Их действие выведено из документации программ и не проверено запуском.

| Класс | Команда (хук: код 0) | Почему проходит |
|---|---|---|
| Программы «чтения», которые пишут в файл | `sort -o F`, `sort --output=F`, `uniq IN F`, `tree -o F`, `xxd IN F`, `xxd -r IN F` | `READ_ONLY` проверяет только имя программы (`reviewer_guard.py:162-167, 187-188`) |
| Читающие команды git, которые пишут | `git diff --output=F`, `git log --output=F` | `GIT_READ` проверяет только подкоманду (`:189-192`) |
| Читающие программы, которые запускают другие | `rg --pre rm …`, `git grep -Orm -e x -- dir`, `sort --compress-program=P` | то же |
| Перенаправление `<>` | `echo x 1<> F` (перезапись), `cat <> new` (создание файла) | `<>` нет ни в `REDIRECTS`, ни в проверке `(:239)`, и он попадает в аргументы |
| Код Python из строки | `python3 -Ic 'import os;os.remove("CLAUDE.md")#/../analysis/review_runs/x'` (также `-Ec`, `-Bc` и т. п.) | проверка `-c` ловит только `-c…` в начале аргумента (`:214`); строка кода принимается за «скрипт», и после `realpath` её «путь» оказывается внутри `analysis/review_runs/` |
| Подмена имени программы | `cp /bin/bash analysis/review_runs/b/cat`, затем `analysis/review_runs/b/cat -c '…'` | проверяется `os.path.basename(words[0])` (`:186`), а `cp` сохраняет бит исполнения |
| Ссылки | `cp -s /abs/CLAUDE.md analysis/review_runs/l && echo x > analysis/review_runs/l` (в одной команде); `cp -l /abs/CLAUDE.md analysis/review_runs/h`, затем `echo x > …/h` | `realpath` при проверке видит ещё не существующую ссылку; жёсткую ссылку `realpath` не распознаёт вообще.
